# inizioseconda

App didattiche di matematica per il liceo (inizio classe seconda), serie ventilii-gif.

- **Test diagnostico d'ingresso** (`index.html`): quiz di 15 domande a risposta
  chiusa (3 per ciascuno di 5 argomenti, estratte da un pool di 60) che valuta
  punti di forza e lacune combinando precisione e rapidità delle risposte.

File HTML singolo, senza build step. Formule in KaTeX, tema chiaro/scuro.
